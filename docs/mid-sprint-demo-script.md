# 中期 Demo 脚本（W3-4 画布节点系统与工作流）

面向中期评审的实操演示流程。按顺序执行即可覆盖 W3-4 全部交付物。建议全程使用本地开发构建（`web` + `backend`），并提前配置好一个可用的 AI 渠道（设置 → 渠道）。

> 时间预算：约 12–15 分钟。每个章节可独立演示，可按观众兴趣跳跃。

---

## 0. 环境与入口
1. 启动前端 `npm run dev`（默认 `http://localhost:3000`），后端 `go run ./cmd`（默认 `:8080`）。
2. 打开「画布库」→ 新建画布（或打开已存在的画布）。
3. 确认右上角出现 **Agent** 按钮与 **智能关联 / 导出剪映草稿 / 合规检测** 入口（左上角菜单内）。

---

## 1. 场景节点：可编辑 + 持久化（Part A）
目标：展示商品 / 分镜 / 视频轨道 / 配方 / 多模态五类专用节点。
1. 左上角菜单 → **新建** → 依次创建 `商品`、`分镜`、`视频轨道`、`配方` 节点。
2. 双击节点标题改名；在节点内编辑结构化字段（商品价格、卖点、分镜场景、配方参数等）。
3. 拖动节点，连线：把 `商品` → `分镜` → `视频轨道` 连起来。
4. 刷新页面（或切到「画布库」再回来）→ 节点内容、位置、连线均保留 → 证明已持久化。
5. 左侧面板「画布元素」可搜索节点并定位。

## 2. 牛顿物理沙盒（Part B）
目标：展示画布具备物理仿真能力。
1. 顶部工具栏点击 **物理沙盒**（Atom 图标）开启。
2. 拖动若干节点到不同高度后松手 → 节点受重力下落、相互碰撞、停在画布底部。
3. 再次点击关闭物理沙盒 → 节点回到交互编辑状态。

## 3. 画布内 Agent 面板（对话 + 过程可视化）
目标：展示在画布内直接调用本地 Agent。
1. 点击右上角 **Agent**（或左上角菜单内连接入口）。
2. 连接本地 Agent（Codex 插件或 `npx -y @basketikun/canvas-agent`）。
3. 在对话中输入需求，例如「把选中的商品节点生成一张海报图」，观察：
   - 对话流式回复；
   - **过程可视化**：任务进度、工具调用、生成结果回插画布；
   - 历史 / 技能 / 日志 三个标签页。
4. 输入 `/` 调用 Skill，输入 `@` 引用画布素材。

## 4. 智能引用 AutoLink（自动连线）
目标：展示语义关联自动连线。
1. 在几个节点的提示词里直接写 `@商品A`（显式引用），或在文案中包含另一个节点的标题。
2. 点击左上角菜单 **智能关联**。
3. 系统自动补齐缺失连线，并提示「已自动建立 N 条关联连线」。
4. 若无新关联，提示「未发现可自动关联的节点」。

## 5. 视频工程编译器（导出剪映草稿）
目标：把画布导出为可导入剪映的工程。
1. 准备：放一个 `视频轨道` 节点，并连线若干 `视频` / `图片` / `文本` / `音频` 节点作为片段。
2. 左上角菜单 → **导出剪映草稿**。
3. 生成 `*.jianying.zip`，内含 `draft_content.json`、`draft_meta.json` 与 `assets/` 素材。
4. 解压后可用剪映「导入草稿」打开（素材路径为相对 `assets/`）。

## 6. 内容合规检测
目标：展示广告法合规自动检查。
1. 在某个节点文案中写入违禁词（如「最佳」「唯一」「包治百病」）。
2. 左上角菜单 → **合规检测**。
3. 弹窗列出每个风险节点：命中词、类型、修改建议、所在字段；顶部给出风险数与合规分。
4. 修正文案后再次检测 → 显示「内容合规，未发现风险」。

## 7. 后端工作流与配方（W3-4 后端）
目标：展示节点图可被后端工作流引擎执行、配方可保存复用。
1. `POST /api/v1/workflows/run` 提交节点图 → 返回按依赖顺序的执行结果（含 `{{变量}}` 替换）。
2. `POST /api/v1/recipes` 保存参数化配方；`GET /api/v1/recipes` 列表；`POST /api/v1/recipes/:id/apply` 一键实例化为新节点图。
3. 配合 #4 的 Agent，可在画布内触发工作流与配方应用。

## 验收清单（演示自检）
- [ ] 场景节点编辑后刷新不丢（持久化）
- [ ] 物理沙盒可开启 / 关闭并影响节点
- [ ] Agent 面板在画布内可用，过程可视化可见
- [ ] 智能关联能自动补齐语义连线
- [ ] 剪映草稿 zip 可被剪映导入
- [ ] 合规检测能定位违禁词并给出建议
- [ ] 后端工作流 / 配方接口可用

## 已知边界（演示时注意）
- 剪映草稿引用素材为相对 `assets/` 路径，需随 zip 一起解压到同目录。
- 合规词库为简化版（绝对化用语 / 虚假宣传 / 医疗保健等），生产需接入完整词库。
- `tsc --noEmit` 在 `node_modules` 第三方类型上有无关告警，业务代码零错误；`vite build` 通过。
