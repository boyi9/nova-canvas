## 环境与启动

### 前置依赖
| 组件 | 版本要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18 | 前端构建 |
| Python | ≥ 3.10 | 后端服务 |
| Git | ≥ 2.30 | 版本控制 |

### 启动步骤

```bash
# 1. 前端（开发服务器，端口 5173）
cd web
npm install
npm run dev

# 2. 后端（FastAPI，端口 8000）
cd web
uvicorn backend.main:app --reload --port 8000
```

| 服务 | 地址 | 说明 |

## 团队协作工作流

协作面板位于画布页（`/canvas/:id`）顶栏右侧入口，共 5 个页签。

### 角色与权限

| 角色 | 能做 | 不能做 |
|---|---|---|
| **owner** | 全部操作，含发布/移除成员/回滚 | — |
| **editor** | 编辑画布、创建版本、提交审批、撤销自己的审批 | 改角色、移除成员、回滚、审批裁决、分享链接管理、创建/取消排期、执行发布、删除项目 |
| **viewer** | 查看画布与版本 | 一切写操作 |

> 注意：**审批裁决、分享链接、排期管理均为 owner 专属**，editor 无权操作。

**红线操作**（owner 专属）：发布、移除/调整成员、删除项目。这类操作会弹**人工确认**，
即使通过 API 调用也不会被自动化链路静默执行。

### 1. 成员页签

1. 输入用户 ID，选择角色（`editor` / `viewer`），点击添加
2. 点击成员行可调整角色或移除
3. 项目创建者自动成为 owner

### 2. 分享页签

1. 选择权限（`viewer` / `editor`），可选设置过期时间
2. 点击生成 → **token 只展示一次**，请立即复制保存
3. 已生成的链接可随时撤销；撤销后立即失效

> 拿到链接的人无需登录即可按权限查看，适合把素材交付给客户或外部合作方。

### 3. 版本页签

1. 编辑告一段落后点击「保存版本」，可填标签与备注
2. 版本列表按时间倒序展示
3. 需要回退时点目标版本旁的「回滚」

> **回滚是安全的**：系统会先把「当前状态」存成一个新版本，再恢复到目标版本。
> 误操作不会静默丢东西，随时可以再回滚回去。

### 4. 审批页签

```
提交审批(editor) → 待审 → 批准(owner) ─┐
                    └→ 驳回(owner)     ├→ 流程结束
                    └→ 撤销(提交者)   ─┘
```

- 提交时填写标题与类型
- owner 裁决时可附意见
- 已裁决的请求不能重复操作（会提示状态不允许）

适用场景：素材交付前的主编审核、对外投放前的终审。

### 5. 排期页签

1. 选择投放渠道（channel），设定发布时间，填写投放内容（JSON）
2. 到点执行发布；执行是**幂等**的——重复执行会被拒绝，防止活动期间重复投放
3. 取消排期同样幂等

### 6. 实时协同状态

协作面板会展示当前在线的成员、各自光标位置与是否正在输入。
这是多人同时编辑时避免互相覆盖的可视化依据。

> **当前实现说明**：在线状态为轮询模式（约每数秒刷新），不是 WebSocket 实时推送。
> 光标移动有一定延迟属正常现象；对实时性要求极高的场景见 `api/p2-reference.md` §1.6 的传输层替换说明。

## 音频生成

用于为视频/图文快速配旁白、背景音乐与音效。

### 查询可用资源

进入音频面板后先浏览目录：
- **音色**：7 种，覆盖中文 / 英文 / 日文，可按语言筛选
- **BGM**：6 首，按情绪分类（轻快 / 治愈 / 史诗 / 紧张 / 轻闲 / 活力），标注 BPM 与时长
- **音效**：9 个，分类为 whoosh / impact / ui / nature / crowd

### 生成流程

```
1. 选音色 → 输入文本 → 生成任务计划（返回预计时长与费用）
2. 点击「渲染」→ 生成 WAV 音频
3. 点击下载 → 得到 .wav 文件
```

### 时长与费用预估

| 类型 | 估算依据 |
|---|---|
| TTS | 中文 4.5 字/秒，英文 14 字符/秒，再按语速缩放 |
| BGM | 按时长计 |
| SFX | 按素材固有时长 |

语速范围 `0.5x ~ 2.0x`，超出会自动钳制。

### 批量生成与原子性

一次可提交多个任务（TTS + BGM + SFX 混合）。
**只要有一个参数非法，整批都会失败**，不会生成"一半成功"的状态——
这是为了保证你看到的预算总和与实际生成内容一致。

### 混音

混音面板支持设置各轨道音量、起止时间，并提供：
- **闪避（Ducking）**：人声说话时 BGM 自动压低 12 dB，说完恢复
- **母线上限检查**：峰值超过设定上限会给出告警
- **BPM 匹配**：输入目标 BPM 自动计算变速倍率（`atempo` 滤镜范围为 `0.5 ~ 2.0`，超出会被钳制）

> **重要说明**：当前「渲染」产出的是本地合成的**测试音频**（正弦波），
> 用于验证流程与时长正确，**不是真实人声**。接入真实 TTS 服务后接口不变，此处会直接产出可用音频。

## 游戏资产生成

把设计规格转成可直接喂给引擎或打包器的参数。

### Sprite Sheet（精灵图集）

1. 输入单帧尺寸（如 32×32）与总帧数
2. 设定每行帧数（columns），系统自动算出行数
3. 可选调整出血（bleed）与内边距（padding）
4. 生成结果包含图集尺寸与**每一帧在图集中的精确坐标矩形**

也可直接选用预设（横版跳跃 / RPG 行走 / 16×16 像素风 / 高质量 idle / 特效序列帧）。

**出血不宜过大**：超过单帧宽度一半会被拒绝——那只会白白浪费显存。

### 纹理（Texture）

输入尺寸与格式，返回**显存占用估算**：
- mipmap 会额外增加约 33% 显存
- 支持 `rgba8888` / `rgb888` / `rg16f`
- 尺寸上限 8192（兼容主流移动端）

### Tilemap（瓦片地图）

输入地图行列与瓦片尺寸，返回索引数据量（按 `uint16` 每瓦片计）。

> **边界说明**：本模块只做**规格计算与校验**，不生成像素。
> 产出参数可直接用于图像生成或打包器配置。

## 常见问题

### 启动类

**Q：`git commit` 报 `env: unknown option -- dir/_/pre-commit`？**
A：`core.hooksPath` 被写坏成了 `--dir/_`（通常是 `husky --dir .husky` 的参数解析出了问题）。
修复：
```bash
git config --unset core.hooksPath
```

**Q：后端启动提示端口占用？**
A：确认 8000 未被占用，或换端口：
```bash
uvicorn backend.main:app --port 8001
```

**Q：前端 5173 打不开？**
A：检查 `npm install` 是否完整；`npm run typecheck` 可提前暴露类型问题。

### 协作类

**Q：提示「无权访问该项目」？**
A：你不在该项目成员列表里。让 owner 在「成员」页签添加你。

**Q：分享链接打不开？**
A：链接已过期或被撤销，让创建者重新生成。

**Q：审批按钮点不了？**
A：该请求已被裁决过，或当前账号不是 owner。

**Q：重复点发布没反应？**
A：这是**幂等设计**——同一排期只能执行一次，避免重复投放。

### 音频类

**Q：下载的音频是"嘟——"的长音？**
A：当前为本地测试合成模式（见上文说明），非真实人声。

**Q：批量提交后一个都没生成？**
A：原子性设计——任一参数非法则整批回滚。检查是否有音色 ID 写错、文本超长（上限 2000 字）等。

**Q：混音的 BGM 没有自动压低？**
A：确认人声轨道的时间区间与 BGM 有重叠；完全错开时闪避不会触发。
