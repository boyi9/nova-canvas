## 开始使用

### 安装与启动
```bash
# 开发环境
npm run dev

# 生产环境构建
npm run build

# 启动服务器
npm run start
```

### 访问应用
- 前端界面: `http://localhost:5173`
- API 服务: `http://localhost:4174`
- 文档: `http://localhost:5173/docs`

### 首次登录
1. 使用账号密码登录
2. 完成个人资料设置
3. 选择角色（导演、编辑、观众）
4. 开始新项目或导入现有项目

## Magic Canvas 使用指南

### 创建新项目
1. 点击首页 "新建项目" 按钮
2. 选择 "Magic Canvas" 模板
3. 使用绘图板进行草图绘制
   - 使用左侧工具栏选择画笔、颜色、画笔粗细
   - 使用右侧图层面板管理图层
   - 使用下方颜色调板选择颜色
4. 完成草图后，点击 "生成视频" 按钮
5. 选择 Seedance 2.0 模板和参数
6. 点击 "开始生成"，等待 AI 处理（通常 10-30 秒）

### 画布操作
- **撤销/重做**: `Ctrl+Z` / `Ctrl+Y` 或 toolbar 中的撤销/重做按钮
- **图层管理**: 使用右侧面板调整图层顺序、透明度、混合模式
- **快捷键**:
  - `B`: 切换画笔工具
  - `E`: 选择工具
  - `Z`: 撤销
  - `Y`: 重做
  - `Ctrl+S`: 保存项目
